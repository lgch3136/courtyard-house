# 归院 · 田野边的家

客户方案展示网页。纯静态 HTML / CSS / JavaScript，可部署在 GitHub Pages。Three.js 引擎本地托管，没有外部 CDN、分析追踪或后端依赖。

## 内容

- 经边界修正的 ImageGen 日景、暮色、屋顶效果图。
- 可旋转、缩放、切换楼层、查看尺寸边界和导出视角的真实三维模型。
- 模型以米为单位。主体所有构件的 XY 范围均在 12 × 11 m 内；没有增加侧向外廊或环形通道。
- 前后院位于主体范围之外，深度未测量；交互模型不虚构院子尺寸。效果图中的院深、邻房和环境为意向表达。
- 主体两层，一层一卧、二层三卧；屋顶茶叙、开敞活动与少量洗晒。

## 本地查看

在此目录执行 `python3 -m http.server 8768 --bind 127.0.0.1`，打开 `http://127.0.0.1:8768/`。模型通过相对地址读取 JSON，需要 HTTP 服务。

## 展示边界

ImageGen 图用于材料、光影和装修意向，不能用照片像素反推精确尺寸。尺寸核对以建筑模型及建筑图纸为准。周边建筑和庭院不是测绘成果。

模型继承建筑会审版数据，尚不是完整施工/BIM模型；不包含基础配筋及机电施工设计。不得直接据此施工。
