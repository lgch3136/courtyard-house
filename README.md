## 两个并列方案

- 12×11米主体控制范围；前后院在外、深度未测；不预设两侧外廊或环绕通道。
- 两案均两层、四卧三卫、后排主卧套房，完整四坡灰瓦顶。
- 方案1保留原房间尺度，中厅同口径约24.0㎡，主卧套房约31.1㎡。
- 方案2适当缩小客房和厨房，中厅约30.6㎡，主卧套房约28.3㎡。
- 取消露台、茶棚、屋顶活动及二层通往露台的固定梯段。二层以上仅有专业检修的屋面夹层，不是第三层居住空间。
- 瓦顶投影仍在12×11米以内，周边600mm是屋顶内部檐沟协调带，不是地面过道。35%坡度、+7.250瓦檐和+8.965脊顶为待专业深化及审批高度复核的方案值。

## 交付文件

- `docs/guiyuan-two-options-tiled-roof.pdf`：13页A3，两版平面、面积比较、湿区详图、屋顶、立面、剖面和外观意向。
- `docs/guiyuan-option2-mep-tiled-roof.pdf`：15页A2，方案2给排水、电气、屋面排水和防水协调图。室内定位只适用于方案2；屋面原则两案共用。
- `docs/guiyuan-fengshui-independent.pdf`：5页A3，九运亥山巳向排盘条件、叠宫和房间建议。153°仅为卫星图估算，属于条件性文化分析。
- `assets/house-option1-tiled.glb` 和 `assets/house-option2-tiled.glb`：Blender导出的真实网格，包括家具、木纹UV材质和瓦片曲面。对应JSON保留图纸几何来源。
- `assets/tiled-r1/`：两版ImageGen外观和Blender分层、屋顶渲染。
- 图像提示词：`design/tiled-roof-prompts-r1.json`，使用内置ImageGen。效果图仅表达材质与氛围，不替代尺寸模型。

网址参数 `?scheme=1#model` 与 `?scheme=2#model` 选择方案；附加 `view=floor1`、`view=floor2` 或 `view=roof` 可定位视图。
