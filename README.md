# 归院 · 田野边的家 / V7

在线地址：https://lgch3136.github.io/courtyard-house/

2026-10-14 更新。纯静态 HTML / CSS / JavaScript，GitHub Pages 部署；Three.js 与 GLTFLoader 本地托管，无外部 CDN、追踪或后端。

## 本版方案

- 12×11米主体控制范围；前后院在外、深度未测，无两侧外廊或环绕通道。
- 两层四卧三卫：一层长者／客卧和公卫；二层后排主卧套房、两间客卧及另一间公卫。
- 主卧套房图示净面约31.1m²，包含睡眠区、书桌区、衣帽区、套内通道和约5.38m²专卫。
- 屋顶分茶叙、开敞活动与少量洗晒，保持开放廊架。
- 153°仅为卫星图估算；飞星页按九运亥山巳向下卦、宅向九宫格法做条件性文化分析。参考链接在网页与PDF内。

## 交付内容

- 16页A3客户方案册：`docs/guiyuan-v7-client.pdf`。包含最新平面、套房及卫浴放大图、室内效果和九宫布局建议。
- 实际Blender导出的模型：`assets/house-v7.glb`，1288个构件，家具为网格，浅木纹为内置ImageGen生成的UV纹理。
- 23张分区卡片：ImageGen材料效果与Blender实际模型视角明确标注。可从卡片进入对应3D房间。
- 室内交互采用材质和家具模型，不能当作照片级漫游；ImageGen图不用于反推门窗或精确尺寸。

## 客户圈点

画圈或标记点后写文字。意见只保存在本机浏览器，无自动集中收集服务。

可复制含全部意见的链接、导出带圈点图片或JSON；另一台设备可通过链接查看或导入JSON。链接使用URL片段承载意见，不发往静态服务器，但收到链接的人可以阅读内容。每张图最多60条，每条500字；长意见建议导出文件。

## 本地查看

执行 `python3 -m http.server 8768 --bind 127.0.0.1`，打开 `http://127.0.0.1:8768/`。模型与图片使用相对路径。

## 使用范围

本版为客户方案与尺寸复核，未签发施工。V5旧二层与湿区布置已变更，不能混用。需以现场测绘、结构／基础、抗震及机电专业深化后的完整施工图开工。

楼梯模型保留踏步高程，梯板下部是可视化表达，不代表结构板厚或配筋。室内图像中的窗外远景、周边建筑和庭院不是测绘成果。

ImageGen提示词见 `design/imagegen-prompts.md` 及 `design/interior-prompts-v7.json`。Three.js许可证见 `vendor/THREE-LICENSE.txt`。
